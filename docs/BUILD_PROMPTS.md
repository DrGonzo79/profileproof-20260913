# Phased build prompts

1. **Consent and import:** Implement two official data-export adapters with direct encrypted upload, malware scanning, tenant isolation, idempotency, strict schemas, partial-parse disclosure, and TTL deletion tests.
2. **Evaluation:** Create a versioned taxonomy and labeled dataset, test false-positive harm and profession-specific bias, add abstention, explanations, and reviewer disagreement workflows.
3. **Human review:** Build a secure reviewer console with least-privilege access, blinded quality sampling, immutable edits, appeals, and completion/deletion receipts.
4. **Candidate decisions:** Add reversible keep/context/privacy/archive planning without platform credentials or auto-deletion; support exports and correction notes.
5. **Commercial pilot:** Add $49 checkout, partner attribution, refund flow, well-being survey, and kill-gate dashboard only after privacy/security review.
